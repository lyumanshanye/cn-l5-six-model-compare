# 中文 L5 七模型横向审阅

独立的静态审阅站，比较七个模型在同一批中文学术文本上的 L5 认知补全重写效果。

- 60 篇论文：简体 30 篇、繁体 30 篇
- 每篇使用同一个 1024-token 原文段
- 7 个模型、共 420 条完整输出
- DeepSeek-V4-Flash 与 GPT-5.6-sol 两位 judge 的双顺序车轮战：每位 2,520 次投票
- 排名同时展示换位一致率和 A 位获选率，便于识别位置偏差
- Qwen 与 DeepSeek 候选关闭 thinking；gpt-oss-120b 保留此前已生成的 reasoning 配置
- 支持语言、领域与标题筛选，左右键切换样本，深浅主题及卡片展开

页面数据直接嵌入 `index.html`，不依赖后端或跨域请求。
